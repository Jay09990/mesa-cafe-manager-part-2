## 2026-11-03 - CSV Formula Injection Mitigation in Custom CSV Generator
**Vulnerability:** The custom CSV exporter in `lib/csv.ts` formatted rows with RFC 4180 quote escaping and a UTF-8 BOM for Microsoft Excel compatibility, but did not neutralize formula trigger characters (`=`, `+`, `-`, `@`, `\t`, `\r`). Public and admin inputs (e.g. booking customer names, notes) exported to CSV could trigger spreadsheet formula execution (CWE-1236 / CSV Injection) when opened in Excel, LibreOffice, or Google Sheets.
**Learning:** Adding UTF-8 BOM to CSVs explicitly targets Excel, making spreadsheet formula evaluation an active risk whenever user-supplied strings are included. Numeric types (like `-42` or `+100`) must be preserved as numbers, while string cells starting with formula trigger characters must be neutralized by prepending a single quote `'` before standard CSV quote wrapping.
**Prevention:** In any custom or shared CSV serialization routine, always inspect string cells against `^[=+\-@\t\r]` and prepend a single quote to force spreadsheet applications to treat the value strictly as plain text.
